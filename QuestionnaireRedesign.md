# New Earth Collective: Hybrid Questionnaire Redesign

## Design Philosophy
**Goal**: Maximum signal, minimum noise. Every question must directly inform:
1. **Community Alignment** - Do they resonate with our values?
2. **How We Serve Them** - What do they need? What can they offer?
3. **Ecosystem Development** - What features/tools should we build?

# QUESTIONS NOT INCLUDED (and why)

## From Current Questionnaire - REMOVED:

| Question | Reason for Removal |
|----------|-------------------|
| "How did you find the New Earth Collective?" (20 words) | Replaced with simpler checkbox version - source matters, essay doesn't |
| "Describe a moment when you chose authenticity over performance" (100 words) | Too introspective/therapeutic for intake. Filters for writing ability, not alignment |
| "How do you respond when triggered in community spaces?" (50 words) | Assumes negativity. Better assessed through actual community interaction |
| "What does 'doing your inner work' look like?" (checkbox) | Performative - people select what sounds good. Actions reveal this over time |
| "What is your relationship with technology?" + "What is your relationship with AI?" | Combined into one question - redundant separation |

## From FeedbackNote.md - REMOVED:

| Question | Reason for Removal |
|----------|-------------------|
| Pronouns | Optional fluff - can add to profile later if they want |
| "Are you currently accepting clients/bookings?" | Too transactional for intake. Better for profile/directory feature |
| "What brought you to The Emergence?" | Event-specific, not evergreen |
| "What are you working on right now?" | Changes constantly - better for profile updates |
| "What support would be most helpful right now?" | Too vague, changes constantly |
| "Dream project or collaboration?" | Nice but fluffy - save for community engagement |
| "Anything else we should know?" | Catch-all that rarely yields actionable info |
| "Anything you DON'T want?" | Negative framing, premature |

# SUMMARY

**Current questionnaire**: ~15 questions, heavy on philosophical essays
**FeedbackNote version**: ~28 questions, comprehensive but long
**This hybrid**: ~25 fields, balanced tactical + alignment

**Estimated completion time**: 12-15 minutes (down from 20-30)

**Key tradeoffs**:
- Removed therapeutic/introspective questions (authenticity stories, trigger responses)
- Kept values alignment questions but reduced word minimums
- Added practical ecosystem-building questions
- Made resource/asset questions optional checkboxes instead of required fields
- Combined redundant tech questions

**Recommendation**: Consider splitting into:
1. **Required intake** (Sections 1-3): ~5 min
2. **Profile builder** (Sections 4-6): ~5 min, can complete later
3. **Preferences** (Section 7): ~1 min, can update anytime
